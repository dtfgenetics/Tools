# Canonical tool ownership

As of 2026-09-27, `dtfgenetics/Tools` is the source of truth for DTFSeeds cultivation tools. `dtfgenetics/Thc` remains the site integration/deployment repository and should consume synchronized mirrors of these files.

Stable public routes: `/tools/`, `/atlas/`, `/terpene-atlas/`, `/ph-meter/`, `/tds-meter/`, `/vpd-chart/`, `/ppfd-chart/`.
