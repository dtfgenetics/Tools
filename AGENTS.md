# Repository guidance

- Preserve every existing dtfseeds.com tool slug.
- Treat data/tool-registry.json as the source of truth for tool ownership and public status.
- Development tools must not be exposed as verified public tools.
- Shared calculations must have deterministic fixture tests.
- Shared UI must remain responsive and accessible on mobile, tablet, and desktop.
- Do not remove the corresponding source from dtfgenetics/Thc until local and live parity have both passed.
