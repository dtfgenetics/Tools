# DTF / THC Tools

Canonical repository for DTF Genetics / Teaching Healthy Cultivation cultivation tools.

This repository owns the tool code published under the existing `https://dtfseeds.com` tool URLs. Repository ownership must not change those public URLs.

## Migration state

The repository is being bootstrapped from `dtfgenetics/Thc`. Until local and live parity are proven, `dtfgenetics/Thc` remains the rollback source.

## Commands

- `npm test` — validate the canonical registry.
- `npm run validate` — validate migrated routes and markers.
- `npm run build` — assemble the tool deployment payload.

Do not mark a tool public unless its route, assets, validation markers, and live verification all pass.
